# Cafe Sales Data Analysis
I performed Cafe Sales Data Analysis by following the professional Data Science Workflow.Although this project is part of my practice but strenghten my data analysis skills that made me confident to discover the hidden dependencies between columns and discover the patterns for meaningful business insights 

## Dataset Source
Cafe Sales Dirty Data — Kaggle
https://www.kaggle.com/datasets/ahmedmohamed2003/cafe-sales-dirty-data-for-cleaning-training

## What I did:
- Loaded the Cafe sales dataset from Kaggle
- Inspected the data for more understanding
- Performed Data Cleaning Process -Eliminated missing values and fake missing values like unknown,error
- Feature Engineering (some business features like Average Item Price,high value orders and time features like hour,month,is_weekend,dayofweek) 
- Exploratory Data Analysis(grouping,filtering,sorting)
- Data Visualization (Top 10 items sold by total revenue,Total revenue by day of week,monthly total revenue)

## Key Findings:
- Salad generates highest revenue
- Weekend buying patterns differ from weekdays
- Uncovered the monthly revenue for Cafe

## Tools used
Python | Pandas | Matplotlib | Seaborn
